# Doodle Jump
Its a very easy jumping game.
## Description
This is project is made using HTML, CSS , JavaScript. The main used is JavaScript. I downloaded the images from online and stored it in a folder. Later used the same from there.
The object was placed at center initially but later i made it move around by changing the velocity using logics. First time i used the gravity function in a project. i Learned how it works.
The other platforms were also added. The loop was created to get contineous platforms. at last the restart button that is spacebar was added to restart the game. EVen the score system was added.
